Guide utilisateur FlexHubTV

De la première connexion à la lecture, sur Android TV (télécommande) comme sur mobile (tactile).

Lecture estimée : 12 minFlexHubTV

Sommaire

1. Qu'est-ce que FlexHubTV ?

FlexHubTV est une application de streaming pour votre propre médiathèque. Au lieu de vous limiter à un seul serveur, elle rassemble plusieurs sources dans une interface unique façon Netflix :

  • Plex (serveurs Plex Media Server) ;
  • Jellyfin ;
  • Xtream / IPTV (comptes Xtream Codes, playlists M3U) ;
  • Backend FlexHub (le serveur maison qui agrège des sources IPTV).

Quand un même film ou une même série existe sur plusieurs de vos serveurs, FlexHubTV les regroupe automatiquement : une seule fiche, un badge « Disponible sur N serveurs », et le choix de la source au moment de lire.

L'application fonctionne sur Android TV (Mi Box, Shield, box opérateur…) à la télécommande, et sur téléphone / tablette au tactile. Certaines fonctions sont réservées au mobile (téléchargements, Cast, incrustation vidéo, gestes tactiles) — elles sont signalées dans ce guide par la mention (mobile).

La lecture s'appuie sur deux moteurs (ExoPlayer et MPV) qui se relaient automatiquement pour lire un maximum de formats.

2. Premier lancement (pas à pas)

2.1 Écran d'introduction

Au tout premier démarrage, une courte vidéo d'intro s'affiche. Vous pouvez appuyer sur « Passer » (en haut à droite) pour aller directement à la connexion.

2.2 Se connecter à une source

L'écran FlexHubTV propose trois types de source. Choisissez celle que vous voulez ajouter en premier :

Source Ce dont vous avez besoin
Plex Un compte Plex (connexion par code, sans mot de passe à taper)
Jellyfin L'adresse de votre serveur + identifiant + mot de passe
Xtream IPTV L'URL du portail de votre fournisseur + identifiant + mot de passe

Connexion Plex (recommandée par code PIN) 1. Sélectionnez Plex, puis « Connexion par code PIN ». 2. L'écran « Associer un compte » affiche un code et l'adresse plex.tv/link. 3. Sur votre téléphone ou ordinateur, ouvrez plex.tv/link, connectez-vous et saisissez le code. 4. L'application détecte la validation automatiquement et poursuit. (Une option « Connexion avancée (Token) » existe pour les utilisateurs expérimentés.)

Connexion Jellyfin - Renseignez URL du serveur (ex. https://jellyfin.exemple.com), Nom d'utilisateur et Mot de passe, puis « Se connecter à Jellyfin ».

Connexion Xtream IPTV - Renseignez URL du portail (ex. http://portail.exemple.com:8080), identifiant et mot de passe, puis « Se connecter à Xtream IPTV ».

2.3 Choisir vos bibliothèques (Plex uniquement)

Après une connexion Plex, l'écran « Choisissez vos bibliothèques » liste vos serveurs et leurs bibliothèques (Films / Séries). Cochez celles à synchroniser, puis « Confirmer ». (Jellyfin et Xtream vont directement à la synchronisation, sans cette étape.)

2.4 Première synchronisation

FlexHubTV télécharge le catalogue de vos serveurs. L'écran de chargement affiche :

  • un anneau doré avec le pourcentage global et le compteur « Serveur x/y » ;
  • les phases : Découverte › Bibliothèques › Extras › Finalisation ;
  • le temps écoulé et une estimation du temps restant ;
  • le détail par serveur (statut, progression, éventuelles erreurs).

Sur une grosse médiathèque, la première synchronisation peut prendre un moment ; les suivantes sont beaucoup plus rapides (mises à jour incrémentales en arrière-plan).

2.5 Utiliser l'app sans Plex

Vous n'êtes pas obligé d'avoir un compte Plex. Une installation Jellyfin seul ou Xtream seul est parfaitement prise en charge : l'accueil et les bibliothèques se remplissent avec le contenu de ces sources.

Ajouter Plex (ou une autre source) plus tard : Réglages → Sources & Serveurs → « Connecter un compte Plex » (ou les sections Jellyfin / Xtream / Backend).

3. Se repérer dans l'application

3.1 Sur Android TV (télécommande)

La navigation se fait avec le pavé directionnel (D-pad). La barre du haut contient :

  • Onglets : Accueil, Séries, Films, Ma liste, Historique, TV en direct.
  • Actions (à droite) : Découvrir (recommandations), Rechercher, Paramètres, l'avatar pour changer de profil, l'horloge, et des pastilles d'état (serveurs hors-ligne, clé API backend manquante, synchronisations en cours).

3.2 Sur mobile (tactile)

La navigation se fait par la barre du bas : Accueil, Séries, Films, TV en direct, Ma liste, Historique, Téléchargements (mobile). La recherche, les réglages et le profil restent accessibles depuis la barre du haut. Le bouton Cast (mobile) apparaît quand un appareil Chromecast est disponible.

4. L'écran d'accueil

L'accueil s'organise en rangées horizontales :

  • Continuer à regarder — reprenez là où vous vous êtes arrêté ;
  • Films / Séries récemment ajoutés ;
  • Ma liste — vos favoris ;
  • Recommandé pour vous et des rangées personnalisées (« Parce que vous avez regardé… », « Reprendre ce soir », « À découvrir dans [genre] »…) ;
  • Films / Séries pour vous — suggestions Moore Metrics (nécessite une clé API, voir §12).

Aperçu au focus : quand vous survolez une affiche, une grande image d'ambiance apparaît en fond avec le type (Film / Série / Épisode) et, le cas échéant, la mention « Plusieurs serveurs ». Sélectionnez une affiche pour ouvrir sa fiche.

Vous pouvez réorganiser ou masquer les rangées de l'accueil dans Réglages → Apparence & Profil.

5. Trouver du contenu

5.1 Bibliothèque Films / Séries

Les onglets Films et Séries affichent une grille. Vous disposez de :

  • un panneau Filtres regroupant : Serveur, Source, Genre, Âge / maturité (Tout, 7+, 13+, 16+, 18+, XXX) et Tri (Date d'ajout, Titre, Année, Note) ;
  • un saut alphabétique pour bondir à une lettre ;
  • le nombre de colonnes réglable (6 ou 7) dans les réglages.

5.2 Recherche

Ouvrez Rechercher : tapez un titre, utilisez la recherche vocale, ou une recherche intelligente en langage naturel (ex. « films de science-fiction des années 90 de moins de 2 h ») lorsque l'assistant IA est configuré.

5.3 Découvrir

Le bouton Découvrir ouvre la recommandation par caractéristiques (Moore Metrics) : réglez des critères et obtenez des suggestions limitées à votre médiathèque (donc directement lisibles). Nécessite une clé API Moore Metrics (voir §12).

6. La fiche d'un film ou d'une série

La fiche présente l'affiche, le synopsis, la distribution, le pourcentage de correspondance et des badges techniques (HD, 4K, HDR, Dolby Vision, Atmos, DTS…).

  • « Disponible sur » : les serveurs qui possèdent ce titre s'affichent en pastilles (3 visibles + une pastille +N qui ouvre la liste complète). C'est la face visible du multi-source.
  • Onglets : Épisodes, Similaires, Collections, Bandes-annonces, et « Dans le même esprit » (Moore Metrics).
  • Actions : Lecture, Télécharger (mobile), Ajouter / Retirer des favoris, Actualiser depuis TMDB, Masquer du hub, Corriger les métadonnées (Scrapper), ajout à une playlist.

Pour une série, l'onglet Épisodes liste les saisons et épisodes : vous pouvez Marquer comme vu, mettre en favori, et suivre la progression épisode par épisode.

Reprise : si vous aviez commencé un titre, une fenêtre propose « Reprendre » ou « Depuis le début ».

7. Regarder : le lecteur

7.1 Contrôles de base

Lecture / pause, retour 10 s / avance 30 s, chapitre précédent / suivant, et épisode suivant avec compte à rebours (lecture automatique activable dans les réglages).

7.2 Choisir la source (multi-source)

Si un titre est disponible sur plusieurs serveurs, une fenêtre « Choisir la source » apparaît : chaque source indique langues, HDR et résolution. Un badge Reprendre signale une lecture en cours ; une source marquée Indisponible (flux cassé) ne peut pas être sélectionnée.

7.3 Sous-titres

  • Télécharger des sous-titres depuis OpenSubtitles ou SubDL (nécessite les clés / identifiants correspondants, voir §12) ;
  • Traduire les sous-titres (IA) vers votre langue à la volée ;
  • ajuster le style et la synchronisation des sous-titres.

7.4 Passer l'intro et le générique

Quand des repères existent, des boutons Passer l'intro, Passer le récap et Passer le générique apparaissent. Le comportement se règle en automatique, bouton ou désactivé (Réglages → Lecture & Sous-titres).

7.5 Confort et menu « Plus »

  • Minuterie de sommeil : arrêt après 15 / 30 / 45 / 60 min ou à la fin de l'épisode.
  • Format d'image : Ajusté, Rempli, Zoom.
  • Menu Plus : qualité, vitesse, synchro audio / sous-titres, égaliseur audio, statistiques détaillées, chapitres, file d'attente.
  • Moteur de lecture : ExoPlayer ou MPV (avec bascule automatique si une source échoue).

7.6 Spécificités mobile

  • Gestes tactiles (mobile) : double-tap à gauche / droite = ±10 s ; glissé horizontal = navigation ; glissé vertical à gauche = luminosité, à droite = volume.
  • Incrustation vidéo (PiP) (mobile) : continuez la lecture dans une petite fenêtre.
  • Cast / Chromecast (mobile) : envoyez la lecture vers un appareil Chromecast.

8. TV en direct / IPTV

L'onglet TV en direct donne accès à vos chaînes :

  • liste et recherche de chaînes, avec favoris ;
  • changement de source : playlist M3U ou backend Xtream ;
  • guide des programmes (EPG) : ouvrez le guide pour voir En cours, Ensuite et À venir ;
  • zapping rapide pour changer de chaîne sans quitter la lecture ;
  • lecture plein écran.

9. Profils et contrôle parental

  • « Qui regarde ? » : plusieurs profils avec avatars ; chaque profil a ses favoris, son historique et ses préférences.
  • Profil Enfants : un profil marqué « Enfant » limite le contenu selon l'âge.
  • PIN par profil : protégez un profil par un code (badge « Protégé par PIN »).
  • Contrôle parental : dans Réglages → Apparence & Profil, définissez un code parental — requis pour quitter le profil enfant.
  • Le filtre de maturité (7+, 13+, 16+, 18+, XXX) se règle dans la vue Bibliothèque (panneau Filtres), pas dans les Réglages.

10. Téléchargements (mobile)

Disponible uniquement sur mobile. Depuis la fiche d'un film ou épisode, appuyez sur Télécharger :

  • choisissez la qualité : Original, 720p (éco données) ou SD (éco données) ;
  • choisissez la source si le titre est multi-serveurs ;
  • suivez le statut (En attente, Téléchargement, Téléchargé, En pause, Échec) et l'espace de stockage ;
  • regardez hors-ligne une fois le téléchargement terminé.

Les téléchargements se font en Wi-Fi par défaut ; activez « Télécharger via données mobiles » dans Réglages → Téléchargements si besoin.

11. Les Réglages en détail

Le menu Réglages est organisé en 7 rubriques par intention (sur TV : deux volets ; sur mobile : liste puis détail) :

  1. Apparence & Profil — profils, changement d'utilisateur Plex, thème, couleur d'accentuation, contour / flou du texte, colonnes de la grille, langue des métadonnées, disposition de l'accueil (réordonner / masquer les rangées), rangées serveur, code parental.
  2. Lecture & Sous-titres — qualité vidéo, moteur (ExoPlayer / MPV), lecture auto de l'épisode suivant, passer l'intro / le générique, langues audio et sous-titres préférées, 2 langues de sous-titres à télécharger, traduction IA des sous-titres (modèle + langue cible + clé).
  3. Sources & Serveurs — Plex, Backend FlexHub, serveurs Jellyfin, IPTV / Xtream (comptes et catégories), serveur par défaut, visibilité des serveurs (masquer un serveur des bibliothèques unifiées), état des serveurs, chaînes TV.
  4. Bibliothèque & Synchro — bibliothèques synchronisées, forcer la synchronisation, fréquence de synchronisation (à chaque lancement, toutes les heures, toutes les 6 h, toutes les 12 h, quotidienne, manuelle), suivi de synchro par source, synchro des notes (TMDb / OMDb), vider le cache.
  5. Intégrations & Clés API — Trakt.tv, appairage TV, Scrapper, Recommandations IA (URL + clé), et les clés API (TMDb, OMDb, OpenSubtitles, Moore Metrics, SubDL).
  6. Téléchargements (mobile uniquement, masqué sur TV) — données mobiles, téléchargements simultanés, connexions par serveur, mode de vérification.
  7. Système & À propos — économiseur d'écran, mises à jour, confidentialité (rapports de plantage), mentions légales, débogage, version, licences, se déconnecter.

12. Intégrations et clés API

Plusieurs fonctions s'appuient sur des services externes. La plupart nécessitent une clé API que vous saisissez dans Réglages → Intégrations & Clés API ; sans clé, la fonction reste inactive (avec un message d'invite).

  • Trakt.tv — synchronise votre activité de visionnage (scrobble, liste à voir). Appairage par code / QR. Selon la version : si Trakt n'est pas configuré dans votre build, l'écran affiche « Trakt.tv n'est pas configuré dans cette version ».
  • Moore Metrics — recommandations (rangées d'accueil, onglet « Dans le même esprit », écran Découvrir). Nécessite une clé API (quota mensuel).
  • Sous-titres — OpenSubtitles (clé API + identifiant + mot de passe pour télécharger) et SubDL (clé API).
  • Traduction IA des sous-titres — au choix : serveur IA auto-hébergé, Groq Llama 3.3 70B ou Gemini 2.0 Flash (clé correspondante requise).
  • Métadonnées & notes — TMDb (métadonnées, affiches) et OMDb (notes IMDb).
  • Appairage TV — configurez votre TV depuis un téléphone / ordinateur (code + QR) pour éviter de tout saisir à la télécommande.

13. Mises à jour de l'application

Sur les versions sideload (installées hors Play Store), FlexHubTV vérifie automatiquement les nouvelles versions. Vous pouvez aussi vérifier manuellement :

Réglages → Système & À propos → Mises à jour → « Vérifier maintenant »**.

Une nouvelle version est téléchargée puis proposée à l'installation ; l'intégrité (SHA-256) est vérifiée avant l'installation.

14. Sauvegarde et transfert

FlexHubTV peut exporter tout votre travail — notes et synopsis récupérés, affiches, favoris, listes, profils, points de reprise, comptes serveurs, clés API et réglages — dans un seul fichier .phbx. Idéal pour changer de TV ou réinstaller sans tout reconfigurer.

Exporter : Réglages → Bibliothèque & Synchro → Sauvegarde & transfert → « Exporter ». Choisissez l'emplacement du fichier via le sélecteur Android (aucune permission de stockage n'est demandée).

Importer : sur le nouvel appareil, … → « Importer », sélectionnez le fichier .phbx puis un mode :

  • Léger (recommandé) : fusion non destructive — favoris, profils, notes et réglages sont ajoutés à ce qui existe déjà. Ré-importable à volonté.
  • Complet (avancé) : remplace intégralement la base locale par celle du fichier ; l'application redémarre pour finaliser l'import.

L'intégrité du fichier est vérifiée par empreinte SHA-256 ; un fichier corrompu est refusé.

⚠️ Sécurité : le fichier .phbx contient vos identifiants de serveurs et clés API en clair (pour pouvoir les restaurer). Conservez-le en lieu sûr et ne le partagez pas.

15. FAQ et dépannage

Du contenu manque ou une rangée est vide. Souvent, une synchronisation est encore en cours (voir la pastille de synchro en haut). Vous pouvez forcer une synchro dans Réglages → Bibliothèque & Synchro.

Une pastille « serveur hors-ligne » s'affiche en haut. Un ou plusieurs serveurs ne répondent pas. Ouvrez la pastille pour voir lesquels, ou activez / désactivez des serveurs dans Réglages → Sources & Serveurs.

Une pastille signale une « clé API backend manquante ». Le backend FlexHub est configuré mais sa clé (X-API-Key) est vide. Ouvrez la pastille, elle vous mène au champ à remplir dans Intégrations & Clés API.

La lecture échoue ou une source est indisponible. Choisissez une autre source dans la fenêtre « Choisir la source » (un titre peut exister sur plusieurs serveurs). Le lecteur tente aussi automatiquement une bascule de moteur / de source.

Les sous-titres téléchargés ne s'affichent pas. Vérifiez la clé API OpenSubtitles (et l'identifiant + mot de passe, requis pour télécharger) ou la clé SubDL dans Intégrations & Clés API.

Je veux masquer le contenu adulte. Utilisez le filtre de maturité dans le panneau Filtres des bibliothèques, et un profil Enfant + code parental pour verrouiller.

Comment repartir de zéro ? Réglages → Bibliothèque & Synchro → « Vider le cache et les données », ou Se déconnecter dans Système & À propos.

16. Confidentialité

Les rapports de plantage (diagnostic) se règlent dans Réglages → Système & À propos → Confidentialité. Un identifiant anonyme peut être copié pour le support. Aucune donnée personnelle identifiable n'est associée aux rapports.
